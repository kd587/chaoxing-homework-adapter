# 超星作业助手（作业页适配版）

这是基于 [LuBanQAQ/chaoxing-script](https://github.com/LuBanQAQ/chaoxing-script) 修改的非商业版本。它能在学习通的**作业答题页**逐题读取题目、向你配置的 AI 接口请求答案，并在页面上选择或填写答案。原项目的考试页功能也保留在脚本中。

> **使用前先知道：** AI 可能答错；脚本填完作业后不会自动保存或提交。请检查答案，再点击学习通页面自己的“暂时保存”或“提交”。

## 三步开始

### 1. 安装脚本

1. 在浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）。
2. 打开 [脚本安装链接](https://raw.githubusercontent.com/kd587/chaoxing-homework-adapter/main/exam_answer_selector.user.js)，在 Tampermonkey 弹出的页面中点击“安装”。如果浏览器直接显示代码，也可以下载 [`exam_answer_selector.user.js`](exam_answer_selector.user.js)，再从 Tampermonkey 导入。
3. 在 Tampermonkey 的“已安装脚本”中确认“超星作业助手（独立修复版）”已启用，版本为 **1.3.3**。如果还装有这个脚本的旧版或原版，先停用它们，避免多个悬浮窗或重复操作。

### 2. 打开真正的作业答题页

从学习通课程中打开一份作业，进入**能看到题目和选项**的页面。已适配的作业页地址通常包含 `/mooc-ans/mooc2/work/dowork`，例如 `https://mooc1-api.chaoxing.com/mooc-ans/mooc2/work/dowork?...`。

进入页面后，右侧会出现“考试助手 AI Pro”悬浮窗。它可以拖动；如果被最小化，点击页面上的 🤖 图标即可展开。课程首页、作业列表页或 Tampermonkey 管理页没有题目，不是开始答题的位置。

### 3. 配置 AI 并试运行

1. 在悬浮窗右上角点击 **⚙️ 设置**。
2. 填写 **API URL**（完整的聊天补全接口地址）、**API Token** 和 **Model**（模型名称），然后点击“保存配置”。默认 URL 是 `https://api.openai.com/v1/chat/completions`；如果使用其他服务，按该服务提供的兼容接口地址填写。
3. 本脚本会把题目截图发送给 AI，所以所选接口和模型需要支持**图片输入**。若服务要求额外请求字段，可在“自定义参数 (JSON)”中填写合法 JSON；通常先保留默认的 `{}` 即可。不要把 Token 写进公开仓库、截图或求助信息。
4. 先点 **“单题解答”**，检查当前题是否正确选择或填写。确认正常后，再点 **“全自动开始”**。
5. 运行结束后逐题核对，并在学习通页面手动“暂时保存”或“提交”。

API 请求可能产生费用，具体以你使用的服务为准。

## 自动运行时会发生什么

- 脚本按页面顺序处理作业题目。它会跳过页面上已经选中选项或已经填写完整填空的题目，避免再次点击把答案取消。
- 点击 **“停止”** 后，同一页面再次点击 **“全自动开始”**，会从未处理的题目继续；停止后才返回的旧 AI 结果不会继续填写答案。
- 刷新作业页后，脚本会重新扫描页面，并跳过页面**仍显示为已作答**的题目。请先确认学习通已经保存了你想保留的答案。
- 每题填写后等待约 0.8 秒，切换下一题后再等待约 0.6 秒；截图和 AI 响应时间另计。
- 作业页处理结束后会停下，**不会自动交卷**。悬浮窗里虽然仍显示原考试功能的“交卷”和“自动交卷”控件，但作业页请以学习通自身的保存、提交按钮为准。

## 常见问题

**没有悬浮窗？** 确认当前是 `chaoxing.com` 域名下的题目页面、脚本已启用，并刷新该页面。检查是否点过最小化，以及是否仍有旧版脚本同时运行。若在课程首页看不到悬浮窗，先进入实际作业答题页。

**只有一题被填写？** 确认点击的是“全自动开始”，并查看悬浮窗底部状态消息。AI 接口报错、截图失败、未找到题目或未能选择答案时，自动运行会停止。先用“单题解答”排查当前题。

**暂停后为什么跳过某题？** 页面上已选择答案或已填完空的题目会被视为已作答。如果要修改，请先手动清除或调整该题，再检查结果；脚本不会判断已有答案是否正确。

**为什么模型没有回答？** 检查 URL 是否为完整接口地址、Token 和模型名称是否正确、模型是否支持图片输入，以及账户额度。悬浮窗底部会显示请求错误。

**换了课程后不适用？** 不同课程的页面结构和题型可能不同。本版本主要适配上述 `dowork` 作业页；未识别的页面需要进一步适配。
