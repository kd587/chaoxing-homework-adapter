# 超星作业助手（作业页适配版）

这是 [LuBanQAQ/chaoxing-script](https://github.com/LuBanQAQ/chaoxing-script) 的非商业用途二次开发版本。原脚本面向单题切换的考试页面；本版本增加了学习通 `/mooc-ans/mooc2/work/dowork` 作业页的逐题处理，保留原有考试页逻辑。

## 功能

- 在作业页按页面题目顺序逐题截图、请求用户配置的 AI 接口并填写答案。
- 点击“停止”后保留当前题号，再次启动时从中断处继续。页面上已选中选项或已填完空的题目会跳过，避免重复点击取消选择。
- 停止后尚未返回的旧 AI 请求不会再修改答案。
- 作业页处理完毕后停止，供用户检查并手动保存或提交；作业页不会自动交卷。

## 安装和使用

1. 安装 Tampermonkey，并停用可能同时运行的原版或旧版脚本。
2. 从 [脚本安装地址](https://raw.githubusercontent.com/kd587/chaoxing-homework-adapter/main/exam_answer_selector.user.js) 安装，或下载本仓库的 [`exam_answer_selector.user.js`](exam_answer_selector.user.js) 后从 Tampermonkey 导入。确认脚本名称为“超星作业助手（独立修复版）”，版本为 **1.3.3**。
3. 打开作业页，在悬浮面板中填写 API URL、Token 和模型。先用“单题解答”确认当前题目能正常选择，再点击“全自动开始”。
4. 完成后检查答案，再使用学习通页面自己的“暂时保存”或“提交”。

作业页在选完每题后等待 0.8 秒，切到下一题后再等待 0.6 秒；截图和 AI 请求用时另计。考试页继续使用原脚本的等待节奏。刷新作业页后，脚本会从头扫描，并跳过页面仍显示为已作答的题目。不同课程和页面版本的题型可能需要进一步适配。

## 测试

```sh
npm ci
npm test
```

测试使用模拟页面，覆盖导航、逐题遍历、停止续跑、已答题跳过、旧 AI 响应失效和作业页不自动提交。真实页面的答案准确性以及平台保存结果需自行核对。
